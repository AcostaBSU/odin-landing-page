# Odin Landing Page

An HTML and CSS website with filler information as an intro project to learn the basics of CSS and flexbox.

## Description

[Odin Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page) is a project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
design to give learners an opportunity to do hands-on HTML and CSS development. The project is comprised of a single webpage with a header, footer, and three important section with the expectation that the learner will match the provided [reference](https://raw.githubusercontent.com/TheOdinProject/curriculum/81a5d553f4073e593d23a6ab00d50eef8620796d/foundations/html_css/project/imgs/01.png) from scratch. 

## Visiting Website
